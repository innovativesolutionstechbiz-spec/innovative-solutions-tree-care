# Innovative Solutions Tree Care — Interactive Website

A responsive six-page static website prepared for deployment on Vercel.

## Pages
- `index.html` — Home
- `services.html` — Services
- `about.html` — About
- `resources.html` — Tree care resources
- `gallery.html` — Gallery / reviews placeholders
- `contact.html` — Estimate request form

## Before publishing
1. Open `contact.html`.
2. Replace `innovative.solutions.tech.biz@gmail.com` in the FormSubmit action URL with the business email that should receive estimate requests.
3. Deploy the folder to Vercel.
4. Submit a test inquiry and confirm email delivery before advertising the form.
5. Replace gallery placeholders with authentic project photos and approved reviews.

## Deploy to Vercel
This is a static HTML/CSS/JS site; no build command is required.
- Build command: leave blank
- Output directory: `.` (project root)
- Install command: leave blank

You can import the project from a Git repository or use Vercel's supported upload/deployment flow. Vercel will assign a `vercel.app` address. A custom domain can be connected later.
